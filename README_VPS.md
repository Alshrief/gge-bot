# تشغيل البوت على سيرفر لينكس VPS وجعله يعمل بشكل دائم كخدمة (Service)

دليل مبسط لشرح كيفية نقل ملفات البوت من نظام ويندوز (Windows) إلى سيرفر لينكس (Linux VPS) وتثبيته وتشغيله في الخلفية دون انقطاع.

---

## 📌 الخطوة 1: تجهيز الملفات ونقلها من ويندوز إلى لينكس

عند نقل ملفات البوت، **لا تقم بنقل مجلد `node_modules`** الخاص بالويندوز، لأن نظام التشغيل مختلف وسيقوم سكربت التثبيت ببنائه وتثبيته تلقائياً على لينكس لتجنب المشاكل.

يمكنك نقل الملفات بإحدى الطرق التالية (اختر الطريقة الأسهل لك):

### الطريقة الأولى: ضغط الملفات بصيغة ZIP ورفعها عبر SFTP (موصى بها)
1. في ويندوز، اذهب لمجلد البوت الرئيسي.
2. قم بتحديد كل الملفات **باستثناء مجلد `node_modules` ومجلد `website/node_modules`** (إذا كانا موجودين).
3. اضغط كليك يمين واضغط **إرسال إلى مجلد مضغوط (Compress to ZIP file)**، وسمِّ الملف مثلاً `gge-bot.zip`.
4. افتح برنامج **FileZilla** أو **WinSCP** على جهازك، واتصل بالسيرفر الخاص بك باستخدام بيانات الـ SSH (الـ IP، اسم المستخدم وغالباً هو `root` أو `ubuntu` والرقم السري أو مفتاح SSH).
5. ارفع ملف `gge-bot.zip` إلى مجلد رئيسي على السيرفر (مثلاً: `/home/ubuntu/` أو `/root/`).
6. اتصل بالسيرفر عبر برنامج الطرفية (Terminal أو PuTTY) وفك ضغط الملف باستخدام الأمر التالي:
   ```bash
   # أولاً قم بتثبيت أداة unzip إذا لم تكن موجودة
   sudo apt update && sudo apt install -y unzip
   
   # قم بفك الضغط في مجلد جديد باسم gge-bot
   mkdir gge-bot
   unzip gge-bot.zip -d gge-bot
   cd gge-bot
   ```

### الطريقة الثانية: استخدام Git (إذا كان لديك مستودع خاص)
إذا قمت برفع كود البوت على مستودع خاص في GitHub:
1. اتصل بالسيرفر عبر SSH.
2. قم بعمل clone للمستودع مباشرة:
   ```bash
   git clone https://github.com/YourUsername/your-repo-name.git gge-bot
   cd gge-bot
   ```
*(إذا كان المستودع يحتوي على إضافات فرعية `submodules` مثل `addons-extra`، سيقوم السكربت بمحاولة تفعيلها تلقائياً)*.

## 📌 الخطوة 2: تشغيل سكربت التثبيت التلقائي `setup_vps.sh`

لقد قمنا بإنشاء سكربت متكامل باسم `setup_vps.sh` يقوم بالمهام التالية تلقائياً:
1. تحديث حزم النظام وتثبيت الأدوات الأساسية (`curl`, `git`, `build-essential`).
2. تثبيت إصدار Node.js v22 (المطلوب لتشغيل مكتبة قاعدة البيانات المدمجة `node:sqlite`).
3. تثبيت مكتبات البوت (Dependencies) في المجلد الرئيسي وفي مجلد لوحة التحكم `website` وبنائها (build).
4. تحويل البوت إلى خدمة نظام (systemd service) باسم `ggebot.service` ليعمل بشكل مستمر في الخلفية ويعيد تشغيل نفسه تلقائياً عند توقفه أو عمل إعادة تشغيل للسيرفر.

### طريقة تشغيل السكربت:
1. تأكد من أنك داخل مجلد البوت على السيرفر:
   ```bash
   cd gge-bot
   ```
2. قم بإعطاء صلاحية التنفيذ للسكربت:
   ```bash
   chmod +x setup_vps.sh
   ```
3. قم بتشغيل السكربت بصلاحيات المسؤول (sudo):
   ```bash
   sudo ./setup_vps.sh
   ```
4. انتظر حتى يكتمل التثبيت وبناء لوحة التحكم. عند الانتهاء سيعطيك السكربت رسالة نجاح متبوعة بالأوامر المفيدة.

## 📌 الخطوة 3: إدارة البوت كخدمة (systemd)

بعد انتهاء السكربت، سيعمل البوت مباشرة في الخلفية. يمكنك التحكم فيه وإدارته باستخدام الأوامر التالية:

* **لمعرفة حالة البوت الحالية وتفاصيل عمله:**
  ```bash
  sudo systemctl status ggebot.service
  ```
* **لإيقاف البوت:**
  ```bash
  sudo systemctl stop ggebot.service
  ```
* **لتشغيل البوت:**
  ```bash
  sudo systemctl start ggebot.service
  ```
* **لإعادة تشغيل البوت (مفيد عند تعديل الإعدادات):**
  ```bash
  sudo systemctl restart ggebot.service
  ```
* **لمراقبة سجل الأحداث (Logs) الخاص بالبوت مباشرة وبث حي:**
  ```bash
  sudo journalctl -u ggebot.service -f
  ```

## 🔒 الخطوة 4: إعدادات الجدار الناري (Firewall) والوصول للوحة التحكم

بشكل افتراضي، يعمل البوت على المنفذ (Port) رقم `3001` (المحدد في ملف `ggeConfig.json`). لكي تستطيع الدخول للوحة التحكم من متصفحك الشخصي، يجب فتح هذا المنفذ في جدار الحماية الخاص بالـ VPS:

إذا كنت تستخدم جدار الحماية **UFW** (شائع جداً في أوبونتو):
```bash
sudo ufw allow 3001
```
إذا كنت تستخدم شركة استضافة توفر جدار حماية خارجي (مثل AWS, Oracle Cloud, DigitalOcean, Hetzner)، فتأكد أيضاً من فتح المنفذ **3001** في لوحة تحكم الاستضافة الخاصة بك (Security Groups / Firewall Rules).

بعد فتح المنفذ، يمكنك فتح المتصفح والدخول عبر الرابط التالي:
```text
http://IP_ADDRESS_OF_YOUR_VPS:3001
```
*(استبدل `IP_ADDRESS_OF_YOUR_VPS` بالـ IP الحقيقي للسيرفر الخاص بك).*

---

## ⚙️ تعديل الإعدادات لاحقاً

إذا رغبت في تعديل أي شيء مثل الـ Port أو ربط بوت ديسكورد (Discord Token) أو شهادات الـ SSL:
1. قم بفتح ملف الإعدادات للتعديل:
   ```bash
   nano ggeConfig.json
   ```
2. بعد الانتهاء من التعديل، احفظ الملف بالضغط على `Ctrl + O` ثم `Enter` للخروج اضغط `Ctrl + X`.
3. قم بإعادة تشغيل الخدمة لتطبيق الإعدادات الجديدة:
   ```bash
   sudo systemctl restart ggebot.service
   ```
